# AI Snap 0.2.9 — Wi-Fi 베타

Windows 화면을 캡처하고 마킹한 뒤 클립보드에 복사하는 도구입니다. Android 앱에서 촬영한 사진도 **같은 공유기의 PC**로 보낼 수 있습니다. PC는 유선 LAN으로 연결해도 됩니다.

현재 일반 배포 전 검증 중인 베타입니다. 지원 대상은 Windows 10/11 x64와 Android 8.0 이상입니다. 문서 스캔과 혼합 DPI 등 남은 검증은 아래에 명시합니다.

## 설치와 업데이트

배포 파일은 Git 소스에 넣지 않고 [GitHub Releases](https://github.com/reezex0-ux/ai-snap-releases/releases)에서 별도로 제공합니다. 소스코드는 비공개이며 공개 배포 저장소에는 사용 안내와 실행 파일·APK만 게시합니다. 릴리스가 아직 게시되지 않았다면 다운로드 파일이 표시되지 않을 수 있습니다.

1. Windows ZIP을 고정된 폴더에 풀고 `AISnap.exe`를 실행합니다. .NET 별도 설치나 관리자 실행은 필요하지 않습니다.
2. 휴대폰에는 같은 릴리스의 Android APK를 내려받아 설치합니다. PC의 QR은 연결용이며 APK 설치 링크가 아닙니다.
3. 배포 파일은 릴리스의 `SHA256SUMS.txt`와 비교할 수 있습니다. Windows 실행 파일은 아직 코드 서명되지 않았습니다.

업데이트는 앱을 종료한 뒤 새 Windows ZIP으로 교체하고 새 APK를 설치합니다. 설정은 Windows 사용자 폴더, 업무 사진은 Android 앱 전용 저장소에 있습니다. **Android 앱을 삭제하면 업무 사진이 사라지므로 기존 앱 위에 업데이트**하세요. Windows 자동실행을 켰다면 실행 파일의 폴더를 유지하세요.

## 화면 캡처

- 가운데 버튼을 누른 채 드래그하고 놓으면 즉시 복사합니다. Shift를 누른 채 시작하면 마킹 도구가 열립니다.
- 기본 단축키 `Ctrl+Alt+S` 또는 설정의 캡처 버튼으로 영역을 선택하고 마킹할 수 있습니다.
- 화살표 `2`, 사각형 `3`, 타원 `4`, 번호 `5`. 기존 도형은 드래그로 이동하고 흰색 핸들로 크기를 조절합니다. `Delete`는 삭제, `Ctrl+Z/Y`는 실행 취소/다시 실행입니다.
- 마킹 후 영역 밖을 왼쪽 클릭하거나 영역 안에서 우클릭하면 복사합니다. 우클릭은 누름과 해제가 모두 영역 안이고 툴바 밖이어야 합니다. 그리기·이동 중 우클릭은 해당 동작만 취소합니다. `Esc`는 동작/캡처를 취소합니다.
- 복사 성공 시 짧은 플래시와 셔터음이 납니다. 원하는 입력창에서 직접 `Ctrl+V`로 붙여넣으세요. 자동 붙여넣기·질문 제출은 없습니다.

설정에서 가운데 드래그를 끄거나 제외할 프로그램을 추가할 수 있습니다. 단축키와 Windows 로그인 시 자동실행도 설정에서 변경합니다. 창 닫기는 트레이로 숨기기이며, 설정 또는 트레이의 종료로 앱을 완전히 종료합니다.

## 같은 Wi-Fi에서 휴대폰 연결

1. PC와 휴대폰을 같은 공유기에 연결합니다. PC의 Ethernet 연결도 지원합니다. 모바일 데이터만으로는 연결할 수 없습니다.
2. PC에서 `휴대폰 카메라` 창을 열고 시작합니다.
3. Android AI Snap의 연결 버튼을 누르고 **앱 안의 QR 스캐너**로 PC 화면을 스캔합니다. 주소 전체를 붙여넣어 연결할 수도 있습니다.
4. Android에서 모니터 아이콘(PC 전송)을 선택해 촬영합니다. PC 클립보드 게시가 성공해야 완료로 표시됩니다.
5. 연결 종료·PC 앱 재시작·8시간 만료 후에는 새 QR로 연결하세요.

Tailscale, VPN 계정, 외부 중계 서버는 사용하지 않습니다. 연결용 주소는 자체 서명 인증서를 사용하는 **Android 앱 전용**입니다. 기본 카메라나 브라우저로 열거나 인증서 경고를 우회하지 마세요. 이전 버전의 인터넷 주소는 새 PC QR로 다시 연결해야 합니다.

연결이 안 되면 다음 순서로 확인하세요.

- 같은 공유기인지 확인합니다. 게스트 Wi-Fi나 AP/클라이언트 격리는 기기 간 통신을 차단할 수 있습니다.
- PC 네트워크가 바뀌었다면 수신기를 다시 시작하고 새 QR로 연결합니다.
- Windows 방화벽에서 본인이 사용하는 사설 네트워크에 앱의 수신이 허용되어 있는지 확인합니다. 앱은 방화벽 규칙을 자동 변경하지 않습니다.
- 회사 보안 정책·VPN이 연결을 막는 경우에는 해당 네트워크 관리자에게 문의하세요.

## Android 사진과 문서

`PC 전송`은 사진을 PC 클립보드로 보내고, `업무 보관`은 휴대폰 앱 전용 보관함에 저장합니다. 보관함에서 명시적으로 공유·내보내기·PC 전송·삭제할 수 있습니다. 외부 자동 업로드는 없습니다.

전송 실패 사진 한 장은 메모리에 남습니다. 다시 전송·업무 보관·버리기를 선택할 수 있으며 화면 회전에는 유지됩니다. **앱/프로세스 종료 후에는 복구되지 않습니다.** 사진 크기는 2/6/12MP 상한 중 선택하며 작은 원본을 확대하지 않습니다.

문서 모드는 **실험 기능**입니다. Google Play 서비스와 첫 사용의 모듈 다운로드가 필요합니다. 한 장을 보정해 PC 전송 또는 업무 보관에 사용합니다. 실제 문서 보정과 실기기 전송은 추가 검증이 필요합니다. 기기에서 사진을 처리하지만 Google SDK는 성능·사용 통계를 전송합니다. [개인정보 안내](PRIVACY.md)를 참고하세요.

## 검증 범위

자동 테스트는 실기기 검증을 대신하지 않습니다. 빌드별 검증 결과는 각 릴리스의 설명에서 확인하세요.

공개 전 남은 주요 확인은 실제 물리 가운데 버튼·우클릭 입력 누수, 125%/150% 혼합 DPI 듀얼 모니터, 새 PC의 방화벽/재부팅, 실제 문서 스캔과 여러 Android 기기의 촬영·업데이트 보존입니다. Wi-Fi 전용 수신·종료는 별도로 실앱에서 확인합니다.
